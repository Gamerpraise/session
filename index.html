Help

How do I use my session?
  1. Tap Copy session (or press and hold the long message we sent to your WhatsApp → Copy).
  2. Paste it into your bot's SESSION_ID setting.
  3. Prefer a file? Put the creds.json in your bot's session folder instead.
  4. Start your bot.
The code doesn't work / no "link" option

Make sure the number is the one on that WhatsApp, with the country code and no leading 0. Update WhatsApp, then try again. If it keeps failing, use the QR code tab instead.

Which session format should I pick?

Plain is base64 of your creds.json and works with most Baileys bots. Choose a prefixed format only if your bot's setup says it needs one (for example Gideon~).

Is it safe?

Your session is created for you, sent to your own WhatsApp, shown here once, and the temporary login is deleted from our server straight after. Keep it private — anyone with it can use your account. You can remove it any time in WhatsApp → Linked devices.
