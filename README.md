## 🧩 Features

- 🔐 Generates sessions for **any Baileys bot**
- ☁️ Stores sessions securely with **MEGA**
- 📱 Web-based **QR Pairing & Pair Pairing**
- 🚀 One-click deploy to:
  - Heroku
  - Render
  - Koyeb
  - Self-hosting platforms
